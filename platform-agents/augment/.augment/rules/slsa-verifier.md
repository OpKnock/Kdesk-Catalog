# slsa-verifier

Verifies SLSA provenance of artifacts and container images with slsa-verifier before deployment.

## Instructions

# slsa-verifier

Verify SLSA provenance before trusting artifacts and images.

## What This Skill Does

- Verifies artifacts against intoto provenance generated by GitHub Actions
- Verifies OCI images with provenance attestations
- Checks source URI, tag, and build workflow inputs
- Prints parsed provenance for review

## When to Use

- Deploy gates that require provenance (SLSA Level 3)
- Downloading third-party binaries built by public CI
- Auditing that artifacts match their declared build source

## Real Commands

```bash
# Verify an artifact
slsa-verifier verify-artifact dist.tgz \
  --provenance-path dist.intoto.jsonl \
  --source-uri github.com/org/repo \
  --source-tag v1.2.3

# Verify an image
slsa-verifier verify-image ghcr.io/org/app:v1.0.0 \
  --source-uri github.com/org/repo --source-tag v1.0.0

# Inspect the provenance
slsa-verifier verify-artifact --provenance-path p.json dist.tgz \
  --source-uri github.com/org/repo --print-provenance
```

## Pipeline Placement

```yaml
- name: Verify SLSA provenance
  run: |
    slsa-verifier verify-artifact dist.tgz \
      --provenance-path dist.intoto.jsonl \
      --source-uri github.com/org/repo --source-tag $GITHUB_REF_NAME
```

## Best Practices

- Pin --source-tag for release builds, not just --source-uri
- Verify in the deploy environment, not only in CI
- Require provenance for all artifacts produced by the build pipeline
- Pair with cosign for signature verification of the images themselves
- Fail deploy if verification errors; never warn-and-continue

## Capabilities

### artifact-verification
Verify binaries and archives against SLSA provenance.

**Commands:**
- `slsa-verifier verify-artifact dist.tgz --provenance-path dist.intoto.jsonl --source-uri github.com/org/repo`
- `slsa-verifier verify-artifact dist.zip --provenance-path provenance.json --source-uri github.com/org/repo --source-tag v1.2.3`
- `slsa-verifier verify-artifact --provenance-path p.json dist.tgz --source-uri github.com/org/repo --print-provenance`
- `slsa-verifier verify-artifact --build-workflow-input "repository: org/repo" --provenance-path p.json dist.tgz`

**Examples:**
- slsa-verifier verify-artifact dist.tgz --provenance-path dist.intoto.jsonl --source-uri github.com/org/repo
- slsa-verifier verify-artifact dist.tgz --provenance-path p.json --source-uri github.com/org/repo --source-tag v1.0.0
- slsa-verifier verify-artifact dist.tgz --provenance-path p.json --source-uri github.com/org/repo --print-provenance

### image-verification
Verify container images with SLSA provenance.

**Commands:**
- `slsa-verifier verify-image ghcr.io/org/app:latest --source-uri github.com/org/repo`
- `slsa-verifier verify-image ghcr.io/org/app:latest --source-uri github.com/org/repo --source-tag v1.2.3`
- `slsa-verifier verify-image ghcr.io/app@sha256:abc123 --source-uri github.com/org/repo`

**Examples:**
- slsa-verifier verify-image ghcr.io/org/app:v1.0.0 --source-uri github.com/org/repo --source-tag v1.0.0
- slsa-verifier verify-image ghcr.io/org/app:latest --source-uri github.com/org/repo
