# Database Migration

Evolve relational schemas safely across environments.

## When to Use

- Adding, altering, or dropping tables and columns
- Backfilling data as part of a deploy
- Reproducing schema state across dev, staging, and prod
- Enabling zero-downtime deploys with expand-contract steps

## Alembic Commands

```bash
# Init migration env
alembic init migrations

# Autogenerate from model changes
alembic revision --autogenerate -m "add users table"

# Review the generated file, then apply
alembic upgrade head

# Roll back one step
alembic downgrade -1

# History and current revision
alembic history
alembic current
```

## Prisma Commands

```bash
# Create + apply migration from schema.prisma
npx prisma migrate dev --name init

# Apply migrations in prod (no interactive prompts)
npx prisma migrate deploy

# Check drift
npx prisma migrate status

# Sync schema without migration history
npx prisma db push
```

## Best Practices

- Never edit applied migrations; create a new one
- Review autogenerated migrations by hand before committing
- Keep one migration per logical change for clean rollbacks
- Backfill data in a separate data migration from the DDL
- Run migrate deploy in CI before releasing new code
- Add down-revisions for every up-revision where possible

## Capabilities

### alembic-migrations
Create and apply SQLAlchemy migrations.

**Parameters:**
- `revision` (string): Target revision id or head/base
- `message` (string): Migration name

**Commands:**
- `alembic init migrations`
- `alembic revision --autogenerate -m "add users table"`
- `alembic upgrade head`
- `alembic downgrade -1`
- `alembic history`

**Examples:**
- alembic revision --autogenerate -m "add email index"
- alembic upgrade +2
- alembic downgrade base

### prisma-migrate
Evolve the database schema from the Prisma schema.

**Parameters:**
- `name` (string): Migration name
- `force` (boolean): Skip confirmation prompts

**Commands:**
- `npx prisma migrate dev --name init`
- `npx prisma migrate deploy`
- `npx prisma migrate status`
- `npx prisma db push`
- `npx prisma migrate resolve --applied 20240101000000_init`

**Examples:**
- npx prisma migrate dev --name add_profile
- npx prisma migrate reset --force
- npx prisma migrate status
