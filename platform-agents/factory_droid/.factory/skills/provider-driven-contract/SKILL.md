# Provider Driven Contract

Provider-driven contract testing with Pact: publish pacts, verify against providers, and gate deploys.

## Instructions

# Provider-Driven Contracts

Contract testing (Pact) verifies that a provider's API satisfies what consumers actually expect.

## What this skill does

- Publishes pacts generated by consumers
- Verifies provider endpoints against pacts
- Gates deployments with can-i-deploy

## When to use

- Many consumers of one API
- Catching contract breaks before deploys

## Real commands

```bash
# Publish pacts
pact-broker publish ./pacts -b http://localhost:9292 -c 1.0.0 -a main

# List latest
pact-broker list-latest-pact-versions -b http://localhost:9292

# Verify provider
pact-provider-verifier --provider-base-url=http://localhost:8080 \
  --pact-urls=./pacts/consumer-orders-api.json --provider-version 1.0.0

# Deploy gate
pact-broker can-i-deploy --pacticipant orders-api --version 1.0.0 --to prod -b http://localhost:9292
```

## Verification in CI

```yaml
- run: pact-provider-verifier --provider-base-url=$BASE_URL --pact-urls=$PACT_URLS
- run: pact-broker can-i-deploy --pacticipant orders-api --version $VERSION --to prod
```

## Best practices

- Verify provider on every PR
- Use can-i-deploy as the final gate
- Tag versions for environment promotion

### pact-contract-testing
