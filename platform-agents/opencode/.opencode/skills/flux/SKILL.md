# Flux

## What this skill does

Flux is a GitOps operator for Kubernetes: it watches git repositories, applies manifests and Helm charts, and keeps the cluster in sync with git. The CLI bootstraps and operates the controllers.

## When to use

- Adopting GitOps for cluster delivery
- Automating Helm releases from git
- Reverting to a previous state by reverting a commit

## Real commands

```bash
# Bootstrap onto a cluster (creates controllers + repo config)
flux bootstrap github --owner=myorg --repository=infra --branch=main --path=./clusters/prod

# Create a source and a kustomization
flux create source git app-infra --url=https://github.com/myorg/app-infra --branch=main
flux create kustomization apps --source=app-infra --path=./apps --prune=true --interval=5m

# Force reconciliation
flux reconcile kustomization apps --with-source

# Inspect state
flux get kustomizations
flux get helmreleases -A
```

## Typical layout

```
clusters/prod/
  flux-system/          # generated by bootstrap
  apps.yaml
  helmreleases/
apps/
  payments/
    kustomization.yaml
    deployment.yaml
```

## Testing

```bash
# Verify source health and last applied commit
flux get sources git -A
flux get kustomizations -o json | jq '.[] | {name: .metadata.name, ready: .status.conditions[0].status}'
```

## Best practices

- One repo or path per environment; keep prod separate from dev.
- Use `--prune=true` so deleted git files are removed from the cluster.
- Enable notifications (flux create alert) for sync failures.
- Test kustomizations in staging before adding to prod path.
- Keep secrets in sealed secrets or external-secrets, never plain in git.

## Capabilities

### flux-gitops
Bootstrap Flux, create sources and kustomizations, and reconcile cluster state from git.

**Parameters:**
- `repository` (string): Git repository holding cluster manifests
- `source-name` (string): Flux source (git) name
- `path` (string): Manifests path inside the repository

**Commands:**
- `flux bootstrap github --owner=myorg --repository=infra --branch=main --path=./clusters/prod`
- `flux create source git app-infra --url=https://github.com/myorg/app-infra --branch=main`
- `flux create kustomization apps --source=app-infra --path=./apps --prune=true --interval=5m`
- `flux reconcile kustomization apps --with-source`
